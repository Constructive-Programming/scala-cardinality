# Security Policy

## Reporting a Vulnerability

Please report security issues privately rather than opening a public issue.
Use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
for this repository, or email the maintainer at <kryptt@gmail.com>.

Please include:

- A description of the issue and its impact.
- Steps to reproduce, or a minimal example.
- Any suggested fix, if you have one.

You can expect an initial response within a few business days. We ask that you
give us a reasonable window to ship a fix before public disclosure.

## Supported Versions

This project is an early work in progress and has not had a release yet. Only
the latest commit on `main` is supported with security fixes.
