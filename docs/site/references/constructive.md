# Constructive

[Constructive](https://www.constructive.dev/) is the consultancy behind
`scala-cardinality`. It works with platform teams on type-driven architecture: fewer
representable states, fewer bugs, and a cardinality lens on design reviews.

The practice covers architecture reviews, embedded senior engineers in Scala, Rust and
TypeScript, agent-native development workflows, and workshops. The argument this
calculator makes in code is the one the consultancy makes in engagements: narrow the
type, and thousands of wrong programs stop compiling.
